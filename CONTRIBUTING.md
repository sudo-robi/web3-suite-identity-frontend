# Contributing to Web3 Suite Identity Frontend

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/web3-suite-identity-frontend.git`
3. Create a feature branch: `git checkout -b feature/amazing-feature`
4. Install dependencies: `npm install`
5. Start development server: `npm run dev`
6. Make your changes
7. Run linting: `npm run lint`
8. Commit: `git commit -m 'Add amazing feature'`
9. Push: `git push origin feature/amazing-feature`
10. Open a Pull Request

## Development Setup

### Prerequisites
- Node.js ≥ 18.0.0
- npm or yarn
- Freighter browser extension

### Commands
```bash
npm run dev          # Start dev server
npm run build        # Build for production
npm run lint         # Lint code
npm test             # Run tests
```

## Tech Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- React Router 6
- Stellar SDK + Freighter

## Code Style

- Use functional components with hooks
- Use Tailwind CSS for styling (no CSS modules)
- Follow TypeScript strict mode
- Write meaningful commit messages

## Pull Request Process

1. Update documentation if needed
2. Ensure all checks pass
3. Request review from maintainers
4. Address feedback promptly
